TimeForSchool provides a hosted HTTP API and an npm package for Korean school data:

- **NEIS Open API** — school profiles, classes, lunch menus, calendars, official timetables
- **Comcigan** — weekly class timetables for schools that use 컴시간

On the HTTP API, every endpoint that targets a school requires **`schoolname`** or **`schoolcode`** (NEIS 7-digit code). There is no default school—`GET /school` also requires `schoolname`. `GET /timetable` defaults to Comcigan; pass **`source=neis`** for the official timetable Open API.

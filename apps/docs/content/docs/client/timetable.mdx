---
title: Timetable
description: fetchTimeTable from Comcigan or official NEIS
---

```ts
import {
  fetchTimeTable,
  fetchNeisTimeTable,
  TimetableAmbiguousSchoolError,
  TimetableSchoolNotFoundError,
} from "@timeforschool/client";
// or: import { fetchTimeTable } from "@timeforschool/client/timetable";
```

## Options

| Field | Type | Description |
| ----- | ---- | ----------- |
| `schoolName` | `string` | Korean school name |
| `schoolCode` | `number` | Optional NEIS 7-digit code for disambiguation |
| `weekNum` | `0 \| 1` | `0` = this week, `1` = next week |
| `source` | `"comcigan" \| "neis"` | Default `comcigan`. Use `neis` when the school does not use 컴시간 |
| `key` | `string` | NEIS API key (only for `source: "neis"`) |

The HTTP API exposes the same switch as `GET /timetable?source=neis`.

## Shape

Both sources return `TimeTableResult`. Slice `[1]` on the day axis to skip Sunday:

```ts
const table = await fetchTimeTable({
  schoolName: "양정고등학교",
  weekNum: 0,
  source: "neis",
  key: process.env.NEIS_API_KEY,
});

const grade1Class3 = table.timetable[1][3].slice(1);
```

HTTP `GET /timetable` already returns that weekday array as `timetable`.

## What NEIS does not publish

Left blank on purpose (same keys, empty values):

| Field | NEIS value |
| ----- | ---------- |
| `teacher` | `""` |
| `dayTime` / HTTP `day_time` | `[]` |
| `original` | `null` |
| `replaced` | `false` |
| `homeroomTeachers` | `[]` |

`subject` comes from `ITRT_CNTNT`. `updateDate` is `LOAD_DTM` as `YYYY-MM-DD` when present.

## Example (Comcigan)

```ts
const table = await fetchTimeTable({
  schoolName: "목운중학교",
  weekNum: 0,
});

const grade1Class3 = table.timetable[1][3].slice(1);
console.log(table.dayTime, table.updateDate);
```

When multiple Comcigan schools match the name, pass `schoolCode` or handle `TimetableAmbiguousSchoolError`.

## Example (NEIS-only school)

외대부고 is registered as **용인한국외국어대학교부설고등학교** (`7531146`). `schoolname=외대부고` will not match NEIS.

```ts
const table = await fetchTimeTable({
  schoolName: "용인한국외국어대학교부설고등학교",
  schoolCode: 7531146,
  source: "neis",
  key: process.env.NEIS_API_KEY,
  weekNum: 0,
});
```

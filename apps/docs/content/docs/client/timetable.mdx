title: Timetable
description: fetchTimeTable from Comcigan (preferred) or official NEIS fallback
---

```ts
import {
  fetchTimeTable,
  fetchNeisTimeTable,
  TimetableAmbiguousSchoolError,
  TimetableSchoolNotFoundError,
} from "@timeforschool/client";
// or: import { fetchTimeTable } from "@timeforschool/client/timetable";
```

Comcigan is the default and the better source when a school uses 컴시간 — it updates faster and includes teachers, bell times, and substitutions. Use `source: "neis"` only when the school does not publish on Comcigan. NEIS is mapped onto the Comcigan result shape; fields the Open API does not publish are left blank. Comcigan output is never changed to look like NEIS.

## Options

| Field | Type | Description |
| ----- | ---- | ----------- |
| `schoolName` | `string` | Korean school name |
| `schoolCode` | `number` | Optional NEIS 7-digit code for disambiguation |
| `weekNum` | `0 \| 1` | `0` = this week, `1` = next week |
| `source` | `"comcigan" \| "neis"` | Default `comcigan`. `neis` is fallback only |
| `key` | `string` | NEIS API key (only for `source: "neis"`) |

The HTTP API exposes the same switch as `GET /timetable?source=neis`.

## Shape

Both sources return `TimeTableResult` (the Comcigan grid). Slice `[1]` on the day axis to skip Sunday:

```ts
const table = await fetchTimeTable({
  schoolName: "양정고등학교",
  weekNum: 0,
});

const grade1Class3 = table.timetable[1][3].slice(1);
```

HTTP `GET /timetable` already returns that weekday array as `timetable`.

## What NEIS does not publish

Left blank on purpose (same keys, empty values) — not omitted, and not filled with guesses:

| Field | NEIS value |
| ----- | ---------- |
| `teacher` | `""` |
| `dayTime` / HTTP `day_time` | `[]` |
| `original` | `null` |
| `replaced` | `false` |
| `homeroomTeachers` | `[]` |

`subject` comes from `ITRT_CNTNT`. `updateDate` is `LOAD_DTM` as `YYYY-MM-DD` when present.

## Example (Comcigan — preferred)

```ts
const table = await fetchTimeTable({
  schoolName: "목운중학교",
  weekNum: 0,
});

const grade1Class3 = table.timetable[1][3].slice(1);
console.log(table.dayTime, table.updateDate);
```

When multiple Comcigan schools match the name, pass `schoolCode` or handle `TimetableAmbiguousSchoolError`.

## Example (NEIS-only school)

외대부고 does not use Comcigan. It is registered as **용인한국외국어대학교부설고등학교** (`7531146`). `schoolname=외대부고` will not match NEIS.

```ts
const table = await fetchTimeTable({
  schoolName: "용인한국외국어대학교부설고등학교",
  schoolCode: 7531146,
  source: "neis",
  key: process.env.NEIS_API_KEY,
  weekNum: 0,
});
```

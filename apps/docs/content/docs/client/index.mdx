The [`@timeforschool/client`](https://www.npmjs.com/package/@timeforschool/client) package wraps upstream Korean school APIs with typed methods and structured errors.

## Subpath exports

| Import | Use case |
| ------ | -------- |
| `@timeforschool/client` | Full surface (NEIS + timetable) |
| `@timeforschool/client/neis` | NEIS only |
| `@timeforschool/client/timetable` | Comcigan timetable only |

## Requirements

- Node.js 20+
- ESM (`"type": "module"` in your app, or bundler that resolves ESM)

## Example

```ts
import { NeisClient, fetchTimeTable } from "@timeforschool/client";

const neis = new NeisClient({ key: process.env.NEIS_API_KEY });

const schools = await neis.schoolInfo({ SCHUL_NM: "양정고등학교" });
const school = schools[0];

const table = await fetchTimeTable({
  schoolName: school.SCHUL_NM,
  weekNum: 0,
});
```

See [NEIS](/docs/client/neis) and [Timetable](/docs/client/timetable) for endpoint-level detail.

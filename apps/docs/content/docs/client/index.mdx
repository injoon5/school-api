The [`@timeforschool/client`](https://www.npmjs.com/package/@timeforschool/client) package wraps upstream Korean school APIs with typed methods and structured errors.

## Hosted HTTP API

The production API at [api.timefor.school](https://api.timefor.school) mirrors these capabilities. Pass **`schoolname`** or **`schoolcode`** on endpoints that need a school—never both. No route defaults to a particular school (including `GET /school`, which requires `schoolname`).

`GET /timetable` defaults to **`source=auto`**: Comcigan and NEIS in parallel, shorter subject wins, weekday gaps fill from the other. Pin **`source=comcigan`** or **`source=neis`** to call one upstream. NEIS Saturday is ignored.

## Subpath exports

| Import | Use case |
| ------ | -------- |
| `@timeforschool/client` | Full surface (NEIS + timetable) |
| `@timeforschool/client/neis` | NEIS only |
| `@timeforschool/client/timetable` | Comcigan / NEIS weekly timetable |

## Requirements

- Node.js 20+
- ESM (`"type": "module"` in your app, or bundler that resolves ESM)

## Example

```ts
import { NeisClient, fetchTimeTable } from "@timeforschool/client";

const neis = new NeisClient({ key: process.env.NEIS_API_KEY });

const schools = await neis.schoolInfo({ SCHUL_NM: "목운중학교" });
const school = schools[0];

const table = await fetchTimeTable({
  schoolName: school.SCHUL_NM,
  weekNum: 0,
  key: process.env.NEIS_API_KEY,
});
```

See [NEIS](/docs/client/neis) and [Timetable](/docs/client/timetable) for endpoint-level detail.
